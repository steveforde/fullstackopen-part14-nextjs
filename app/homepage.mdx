# Welcome to Blog App

A simple, modern blogging platform built with Next.js. Write posts, share ideas, and connect with other writers in a clean, distraction-free space.

## About This Project

This app was built as part of a full-stack development course, focused on modern web development practices using the Next.js App Router, server components, and a PostgreSQL database managed through Drizzle ORM.

## Features

- **Create and manage blog posts** — write, edit, and publish your thoughts with a simple editor
- **User authentication** — secure registration and login system
- **User profiles** — every writer gets their own personal page
- **Comments** — readers can engage directly with posts
- **Responsive design** — works well on desktop, tablet, and mobile

## How It Works

Once you register an account, you can log in and start writing right away. Each post you publish appears on your profile and in the main blog feed, where other users can read and comment on it. You can edit or delete your own posts at any time from your dashboard.
